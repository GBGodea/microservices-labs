Основное решение: семь bounded contexts и восемь независимо развёртываемых сервисов. Разблокировка входит в сценарий поездки; команды устройству принадлежат Fleet Service. Телеметрия отделена от управления парком. Каждый сервис владеет своими данными, поиск строит проекцию по событиям.
